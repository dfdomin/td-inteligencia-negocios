# Semana 2 - Consumidor digital y propuesta de valor

## Proposito

Comprender como cambia el comportamiento del cliente y como eso exige redisenar experiencias.

## En clase

- Identificar momentos de friccion en compra, pago, entrega y posventa.
- Construir un journey map simple de Mercado360.
- Proponer una mejora digital de alto impacto y bajo costo.

## Evidencia

Journey map con dolor, emocion, canal, dato requerido y oportunidad.
