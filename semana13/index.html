Semana 13 — Viabilidad y caso de negocio

Costos, beneficios, supuestos y KPIs · IUB — Inteligencia de Negocios

🎯 Propósito de la semana

Evaluar si la estrategia digital propuesta es conveniente, viable y defendible ante una gerencia con recursos limitados.

La viabilidad no es solo financiera. Una iniciativa puede tener retorno económico, pero fallar por falta de datos, talento, adopción, seguridad, soporte o claridad estratégica. Por eso el caso de negocio debe integrar beneficios, costos, riesgos y supuestos.

📚 Marco y contenido

1. Caso de negocio ligero

Para una pyme o unidad pequeña, el caso de negocio debe ser suficiente para tomar una decisión informada sin exigir un modelo financiero complejo. Debe mostrar qué se gana, qué se invierte, qué se arriesga y qué se aprenderá.

ComponenteContenido esperadoEjemplo
Beneficios cuantitativosMejoras que pueden medirse en dinero, tiempo o volumen.Reducción de devoluciones, mayor conversión, menos horas de reproceso.
Beneficios cualitativosMejoras relevantes pero menos directas de monetizar.Confianza del cliente, trazabilidad, calidad de datos, reputación.
Costos directosLicencias, desarrollo, equipos, consultoría, capacitación.CRM mensual, dominio, computador, sesión de formación.
Costos ocultosTiempo del personal, migración de datos, soporte, resistencia.Horas de limpieza de base de clientes o carga inicial de inventario.
SupuestosCondiciones que deben cumplirse para lograr el beneficio.Que el 70% del equipo registre datos completos en el primer mes.
RiesgosEventos que pueden reducir el valor esperado.Baja adopción, proveedor inestable, datos incompletos, sobrecosto.

2. Métricas financieras simples

MétricaFórmula simpleUso
Inversión totalCostos iniciales + costos recurrentes del periodo evaluado.Define el tamaño real del compromiso.
Ahorro o beneficio anualValor monetario estimado de mejoras en ventas, costos o productividad.Traduce la mejora operativa a impacto económico.
Retorno sobre inversión (ROI)(Beneficio neto / inversión total) x 100.Compara alternativas con una escala común.
Periodo de recuperaciónInversión total / beneficio mensual promedio.Estima cuántos meses tarda en recuperarse la inversión.

3. Análisis de sensibilidad

Como las propuestas se basan en supuestos, se debe revisar qué pasa si el beneficio es menor o el costo mayor al esperado. Un análisis básico puede presentar tres escenarios:

EscenarioSupuestoInterpretación
ConservadorAdopción baja, beneficios lentos, costos algo mayores.Sirve para saber si el proyecto sobrevive a condiciones difíciles.
BaseSupuestos razonables según evidencia del diagnóstico.Escenario principal para recomendar.
OptimistaAlta adopción, beneficios rápidos, costos controlados.No debe ser el único argumento de decisión.
Advertencia: no infles beneficios para que el proyecto “dé”. Es preferible una recomendación honesta: iniciar con POC, reducir alcance, cambiar tecnología o no implementar todavía.

⚙️ Actividad práctica

Preparar una ficha de viabilidad y los argumentos para la sustentación final.

Sección de la fichaContenido mínimo

Evidencia: Caso de negocio con beneficios, costos, supuestos, KPIs, escenarios y recomendación ejecutiva.
