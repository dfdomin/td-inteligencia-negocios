# Observaciones sobre TGA04 y TGA05

## Patrones encontrados

Los repositorios de referencia trabajan con:

- `README.md` como puerta de entrada.
- Plan maestro de contenido.
- Caso transversal tipo narrativa de negocio.
- Carpetas `semanaN`.
- Material para estudiante y notas para profesor.
- Evaluaciones conectadas con el caso.
- Posibilidad de evolucionar hacia HTML, dashboards y pruebas.

## Adaptacion a TD

Para Transformacion Digital se mantiene el mismo principio, pero el primer entregable se deja en Markdown porque el reto inicial es curricular: seleccionar, secuenciar y aterrizar un microcurriculo demasiado amplio para 2 horas reales por semana.

## Pendientes de validacion
