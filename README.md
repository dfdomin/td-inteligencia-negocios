# TD - Transformación Digital en la Empresa

Repositorio academico para desarrollar el material de estudio del modulo **Transformación Digital en la Empresa** del programa **Profesional en Inteligencia de Negocios**.

## Entradas principales

- `MODULE_CONTEXT.md`: identidad compacta del modulo para futuras sesiones con IA.
- `PLAN_CONTENIDO_TD.md`: ruta pedagógica de 14 semanas.
- `Caso_Estudio_Mercado360.md`: caso formativo transversal del modulo.
- `casos/`: caso formativo y casos espejo para parciales.
- `evaluaciones/`: actividades de parcial y entrega final.
- `exposiciones/`: estrategia, roles y rubrica para exposiciones aplicadas.
- `semanaN/README.md`: material base del estudiante por semana.
- `semanaN/notas_profesor.md`: guia docente de sesión.
- `transformacion_microcurriculo.md`: microcurrículo base existente.
- `Reporte_Estudiantes-18.pdf`: reporte de estudiantes existente.

## Enfoque

El modulo declara 4 horas semanales, pero esta version se disena para una realidad de **2 horas presenciales por semana**. Por eso cada semana se organiza con:

- un concepto central;
- una demostracion o taller corto;
- una aplicación al caso formativo;
- una evidencia concreta;
- una exposición breve cuando ayude a avanzar contenido.

## Alineacion curricular

**Unidad de competencia base:** UC2. Gerenciar estrategicamente la organización basado en Sistemas de Información para generar valor en la organización.

**RA de programa propuesto para validación:** Gestiona información estratégica y sistemas de información para formular acciones que generen valor organizacional mediante tecnologías digitales.

**RA del modulo priorizado:** Proponer estrategias para la transformación digital de una organización determinada, basado en tecnologías que transforman y mejoran el entorno organizacional.

## Casos de estudio

El caso formativo recomendado es **Mercado360**, una empresa comercial mediana que vende por tienda física, WhatsApp e Instagram, pero tiene procesos manuales, datos dispersos y baja trazabilidad del cliente.

Siguiendo el patron de `ProcesamientoInformacion`, las evaluaciones usan casos espejo:

- Semana 5: **RetailNova**, diagnóstico y oportunidad digital.
- Semana 10: **SaludConecta**, propuesta de solución digital.
- Semana 14: **LogisCaribe**, estrategia integral de transformación digital.

Esto permite practicar con Mercado360 y evaluar transferencia en contextos nuevos.
